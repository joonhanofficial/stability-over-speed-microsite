# Stability Over Speed Microsite

## Purpose
This is a one-page interactive microsite built for the **"Stability Over Speed"** analytical case study. It serves as an interactive proof asset demonstrating a SQL and Tableau analytical project, making the case study easier to inspect, understand, and share. The visual theme is adapted to macroeconomic signal interpretation, SQL data transformation, and Tableau comparative analysis with a dark premium analytical aesthetic.

## Files Created
1. `index.html` - Semantic HTML structure and content.
2. `style.css` - Custom styling, layout grid, variables, and responsive design.
3. `script.js` - Interactivity, smooth scrolling, and mobile touch fallback for the diagnostic cards.
4. `README.md` - Documentation and instructions.

*Note: This site uses plain HTML, CSS, and JavaScript only. No React, Next.js, npm, backend, external dependencies, or frameworks were used.*

## GitHub Pages Deployment
This repository is configured as a static GitHub Pages compatible microsite. 

**Note: GitHub Pages must be enabled manually.**
To enable it:
1. Go to your repository settings on GitHub.
2. Navigate to **Pages** on the left sidebar.
3. Under "Build and deployment", set the Source to **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Your site will be published shortly at `https://[your-username].github.io/stability-over-speed-microsite/`.
