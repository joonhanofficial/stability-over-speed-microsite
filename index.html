Stability Over Speed

A SQL and Tableau diagnostic examining how inflation pressure changed the reading of post-COVID GDP recovery.

Headline GDP rebound looked positive after 2020. This diagnostic tested whether that recovery still looked stable once inflation was added as a second pressure signal.

A rebound number is not the same as recovery quality.

GDP growth can show whether output fell and later recovered. But GDP alone does not show whether that recovery happened under rising price pressure. This project added inflation as a second signal to make the recovery reading more cautious.

From raw public files to an analysis-ready comparison table.

The project used SQL in BigQuery to clean, reshape, and join raw World Bank GDP and inflation files into a country-year analytical table suitable for Tableau visualization.

  1. Imported raw World Bank GDP and inflation files
  2. Filtered selected countries and years
  3. Reshaped wide-format year columns into long country-year records
  4. Standardized country and year fields
  5. Joined GDP growth and inflation into one analytical table
  6. Validated row count, country scope, year scope, and missing values
  7. Exported the processed CSV for Tableau visualization
Final table

A stronger reading, not a complete economic model.

What this analysis can suggest

  • GDP rebound alone can overstate recovery strength
  • Inflation adds useful pressure context
  • Recovery speed and recovery quality should be interpreted separately
  • Cross-country comparison helps reveal different recovery patterns

What this analysis cannot prove

  • It does not establish causality
  • It does not explain all macroeconomic drivers
  • It does not define full economic stability
  • It uses only GDP growth and inflation across five selected countries

Recovery speed did not always mean recovery stability.

GDP showed the rebound, but inflation changed how that rebound should be interpreted.

The value of the project was not predicting the economy. It was building a cleaner analytical lens for reading a headline metric with more caution.
